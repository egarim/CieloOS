# Указатель и клавиатура на настоящем рабочем столе

Агент открывает приложение, печатает в нём и сохраняет файл — на том рабочем столе
XFCE, который перед вами, а не на headless-копии.

## На что смотреть

**Он щёлкает по центру именованных элементов, а не по угаданным пикселям.**
Восприятие берётся из собственного дерева доступности рабочего стола, поэтому агент
запрашивает «кнопку Save» и получает её точный прямоугольник. Когда дерево не может
что-то описать — холст, некоторые значки, — снимок экрана и модель зрения служат
запасным вариантом, а не режимом по умолчанию. Именно этот порядок позволяет всему
этому работать с небольшой локальной моделью и означает, что по умолчанию ничто с
вашего экрана не покидает машину.

**Ввод текста может остановиться и спросить.** Нажатия клавиш — самое рискованное,
что агент может сделать на рабочем столе: текст, прочитанный с экрана, способен
склонить его к вводу команды или секрета. Вы можете выдать разрешение с
ограниченным сроком, которое позволит ему печатать, не спрашивая каждый раз: это
решение, принимаемое один раз, вместо запроса, который вы закрываете двадцать раз.

**Вы можете забрать мышь.** Вас ничто не блокирует. Агент — ещё один обитатель этой
сессии, а не её владелец.
