# A document an agent made, that Excel opens

The agent builds a small budget through the spreadsheet surface, and you open it in
ONLYOFFICE on this desktop.

## What to watch for

**Every edit is a typed command, not a keystroke.** The agent is not driving a
spreadsheet application by clicking around it — it is issuing structured commands
that the machine checks, applies and records. That is why an edit can be previewed
before it happens and described afterwards in terms of what changed.

**The file is real.** It opens in ONLYOFFICE here and in Excel on someone else's
laptop. The point of an agent-operated computer is ordinary files that ordinary
software reads, not a private format only this machine understands.
